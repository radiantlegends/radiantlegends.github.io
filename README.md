# radiantlegends.github.io

This repository contains the source code for my personal portfolio website, available at: https://radiantlegends.github.io/

## Purpose
This project serves as my central professional hub, showcasing my frontend development work, UI architecture approach, and selected projects. The site is continuously refined as my skills and design direction evolve.

## Technical Notes
- **Mobile‑first CSS architecture:**  
  Styling for the portfolio page are written mobile-first, using min-width breakpoints to progressively enhance layouts for larger screens.
- **Lightweight, modular structure:**  
  Components and sections are organized for clarity, maintainability, and future expansion.
- **Vanilla HTML/CSS/JS:**  
  The main site is intentionally framework-free to keep the codebase transparent and easy to iterate on.

## Status
Active development with ongoing improvements and refinements. Links to other projects will be added as they are made.
